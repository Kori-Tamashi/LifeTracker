# Реестр интеграций

Статус: список для исследования. Официальная документация ещё не проверена; возможности ниже являются желаемыми, а не подтверждёнными.

| Источник | Желаемый результат | Проверить до включения в ТЗ |
| --- | --- | --- |
| Т-Банк | Автоматическое получение операций без ручной загрузки | Доступный владельцу способ интеграции, состав данных, задержка, авторизация, дубликаты; реализуемость не подтверждена |
| Telegram | Ввод и обзор через бота | Команды, авторизация, размещение, доступ к данным при выключенном Mac |
| macOS | Время за приложениями и работой | Разрешения, доступные API, простой, определение работы, энергопотребление |
| Геопозиция | Контекст прогулок и мест | Источник, точность, разрешения, необходимость хранения точных координат |
| Steam | Игровая активность | Детализация истории, приватность профиля, лимиты, точность интервалов |

Для каждого исследования фиксировать дату, ссылки на официальную документацию, ограничения, результат минимального эксперимента и альтернативу при недоступности данных. Telegram-бот и чтение личных переписок — разные сценарии; доступ к перепискам не входит в подтверждённые требования.
