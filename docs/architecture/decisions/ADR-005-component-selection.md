# ADR-005 — Базовый стек и условный комплект ИИ

Статус: **выбрано проектировщиком** в рамках порученного сравнения; готовность к эксплуатации не подтверждена. Дата: 19 ноября 2026 года. Новые числовые бизнес-правила алгоритмов остаются предложениями.

## Контекст

Нужны локальность, macOS/Apple Silicon, контейнерная бизнес-часть при допустимых ресурсах, Clean Architecture/SOLID, полное тестирование, бесплатные инструменты и общий лимит 10–20 ГБ. [Сравнение с источниками](../../research/component-comparison.md).

## Выбор

- Core: C#/.NET 10 LTS, ASP.NET Core; Domain/Application/Infrastructure/Host отдельными сборками внутри модулей при необходимости.
- UI: SwiftUI с точечным AppKit; условный iPhone bridge на Swift.
- Store: SQLite, EF Core SQLite; специализированные SQL/backup через Microsoft.Data.Sqlite внутри Infrastructure. Один core-владелец записи.
- Jobs: таблицы inbox/jobs/outbox + BackgroundService, без отдельного брокера.
- Retrieval: FTS5 + связи событий/людей; embeddings только при недостаточном recall.
- Inference: нативные llama.cpp и whisper.cpp; typed application port. Не встраивать SDK модели в Domain.
- API: versioned HTTP/JSON + OpenAPI, SSE для прогресса/потока; Telegram long polling.
- Tests: xUnit v3, ArchUnitNET, Swift Testing/XCTest; GitHub Actions и отдельный изолированный Mac-стенд.
- BPMN: документируемые XML/DI, без execution engine.

## Условный выбор моделей

Первый кандидат — Qwen3.5-4B quant для текста/фото и multilingual Whisper small. Text fallback — Qwen3-4B-Instruct-2507; medium STT — challenger. Производитель, revision, конвертация, лицензия, SHA и полный размер ещё должны быть закреплены manifest. Нет утверждения, что модель уже запущена или укладывается в 15 секунд.

## Последствия

Два собственных продуктовых языка и готовые inference-бинарники вместо отдельного Python AI-сервиса. Нативный интерфейс удобен Apple API, ядро переносимо на Linux; цена — контракты/маппинг между языками. SQLite не решает будущее многопользовательское серверное масштабирование автоматически. Конкретные версии пакетов фиксируются при scaffolding и проверяются совместной сборкой.

## Условия пересмотра

1. Docker/volume/WAL или footprint не проходят проверку: перейти к нативному запуску того же core либо согласовать путь данных; не делить одну БД между VM и host.
2. SQLite блокировки/денежные расчёты не удовлетворяют требованиям: сравнить PostgreSQL на воспроизводимом стенде до R3.
3. AI bundle не проходит русский корпус/latency/disk: сменить candidate/runtime, сообщить о недостижимости цели; облако не включать скрыто.
4. FTS5 не даёт достаточного retrieval: добавить локальные embeddings по отдельному ADR.
5. Нет бесплатной установки/entitlements Apple bridge или доступа банка: интеграция blocked, альтернативы согласовать отдельно.

Решение выбирает компоненты для дальнейшей реализации. Оно не отменяет шлюзы SP-01–07 и не является их фиктивным закрытием.
