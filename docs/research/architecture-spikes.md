# План архитектурных экспериментов

Статус: задания на исследование, не выполненные проверки. Документальное сравнение и выбор компонентов уже выполнены в [component-comparison.md](component-comparison.md); это не закрывает экспериментальные проверки. Использовать официальные источники и синтетические данные; фактические настройки устройств остаются локальными.

| ID | Вопрос | Эксперимент и ожидаемое свидетельство | Решение после |
| --- | --- | --- | --- |
| SP-01 | Screen Time | Проверить API/entitlements/регион и чтение категорий/агрегатов; показать минимальный разрешённый сценарий | Доступный источник R1 либо явный запрос изменения объёма |
| SP-02 | Health bridge | Проверить бесплатную установку, срок подписи, фон, batch передачу и локальную связь | Реальный объём интеграции без платной подписки |
| SP-03 | Local AI | Сравнить кандидатов speech/text/image по лицензии, диску, RAM, cold/warm latency, качеству русского synthetic corpus | Стек worker и выполнимость 15 секунд; не обещать до замера |
| SP-04 | Core runtime | Сравнить нативное ядро/контейнер, host-worker transport, старт/сон/остановку, общий диск | ADR размещения и упаковки |
| SP-05 | Store/jobs | Транзакции, dedup, migration, lease recovery, crash до/после commit, snapshot restore | СУБД и реализация очереди/outbox |
| SP-06 | T-Bank | Проверить легитимный бесплатный доступ ко всем типам данных, историю и обновление, без передачи секретов в Git | Допуск R3 либо откладывание |
| SP-07 | CI/Mac | Проверить бесплатные runners, версию ОС, UI test tooling, isolated Apple Silicon benchmark | Реальные jobs и gates, лимиты без оплаты |
| SP-08 | Diagrams | Установить локальный фиксированный PlantUML/Graphviz, отрендерить 11 схем, проверить читабельность | Визуально проверенные SVG и CI-render |

Для каждого отчёта: дата, версии/источники, методика, синтетические входы, результат, ограничения, размер артефактов, рекомендованное ADR. Одна доступная ручная выгрузка не доказывает требуемый автоматический режим.
