# Бизнес-процессы BPMN 2.0

Статус: baseline 1.0. Это бизнес-модели с ролями, user/service/business-rule tasks, XOR-шлюзами и timer catch event; `isExecutable=false`. Они не требуют покупки или установки BPMN execution engine. Определения/DI совместимы со схемами [OMG BPMN 2.0.2](https://www.omg.org/spec/BPMN/machine-readable).

Детальные [алгоритмы](../architecture/algorithms/README.md) содержат транзакции, условия и псевдокод. BPMN показывает путь ответственности и исходы, а не каждый SQL-вызов. В BP02 быстрый ответ и фоновое извлечение объединены в сервисный этап; конкуренция ветвей уточнена ALG-03, не является параллельным BPMN fork. BP04 — планирование/обзор; закрытие месяца показано BP09, портфельBP11; налоговая декларация вне scope.

Дорожки обозначают роли в одном процессе; внешние сервисы представлены действиями адаптеров, не вторым пулом с незаконными sequence flows. Задачи детерминированного расчёта не принадлежат роли ИИ. XOR-ветви имеют условия и default; условия описательные, не исполняемый DSL. Ожидаемые ошибки возвращаются как результаты сервисных этапов и ветвятся; исключения runtime обрабатывает ALG-02, не считаются успешным завершением процесса.

U/S/R в SVG — сокращённые маркеры user/service/business-rule tasks. SVG — навигационный preview; нормативный редактируемый артефакт `.bpmn` содержит полные типы элементов и DI. Для полноценного редактирования использовать совместимый локальный BPMN-редактор, не Mermaid flowchart. Числа политик зафиксированы BR-01–10 baseline1.0.

## Воспроизводимость и проверки

Единый источник генерации — [catalog.json](catalog.json). `python3 tools/build_processes.py` создаёт XML+DI и SVG; `--check` проверяет отсутствие рассинхронизации. Ручная правка generated `.bpmn` без обновления каталога будет обнаружена; если требуется свободное редактирование в Modeler, сначала принять изменение этого правила и отказаться от генерации соответствующей модели.

Тесты проверяют уникальность IDs/координат, существование ссылок, исходы XOR, достижимость каждого узла от start и возможность дойти до end, а также соответствие DI. Это не полное доказательство soundness BPMN и не тест реализации приложения.

Все одиннадцать XML проверены `xmllint --nonet --schema BPMN20.xsd` по официальным OMG XSD, скачанным во временную папку 19 ноября 2026 года. Схемы не включены в репозиторий; локальная structural/graph проверка в CI работает без их загрузки. XSD проверяет формат, а не бизнес-правильность. Внешние рендер-сервисы не используются.

Одиннадцать SVG отрендерены локально и просмотрены; после проверки скорректированы обходы узлов и выходы XOR. Автотест дополнительно запрещает пересечение стрелкой посторонней задачи. Рендер preview не заменяет проверку импорта в конкретный BPMN-редактор; такой импорт пока не выполнен.
