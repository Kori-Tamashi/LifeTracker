# Интерфейсы baseline 1.0

## macOS

Главное окно: слева навигация «Персонаж / Дневник / Питание / Финансы / Квесты / Настройки» по доступным capabilities; справа содержимое. Первое открытие — персонаж. Нижняя строка показывает состояние локального сервиса и последний успешный импорт, не технический stack trace. Секции будущего этапа скрыты из основной навигации; в настройках roadmap есть явное «ещё недоступно».

| Экран | Основные элементы и действия | Пустое / ошибка |
| --- | --- | --- |
| Персонаж | 2D герой, баланс, 4 показателя, источник/время, кнопка «Отметить состояние», buffs/debuffs отдельно | Unknown вместо заполненных шкал; service unavailable с retry, последнее состояние с датой |
| Быстрая отметка | 4 sliders 0–10 шаг 0.5, любой поднабор, время/комментарий, сохранить | Незаданные поля не 0; inline validation; повтор save возвращает прежний receipt |
| История показателя | Все отметки по дате, фильтр источника, correction с reason, explanation | Пустая история с первым действием; revision conflict предлагает перезагрузить/сравнить |
| Дневник | Лента, календарь, отчёты; запись голоса/текста, обработка по этапам | Модель unavailable не теряет принятый ввод; pending confirmation отдельный inbox |
| Разговор | Turns и streaming response, stop, resume, список предложенных записей | Явный статус «принято/обрабатывается/записано», не ложное «сохранено» до commit |
| Вывод | Формулировка, confidence qualitative, episode links/цитаты, contradictions, «Не согласен», «Исправить факт» | Stale/исторический вывод визуально помечен, не в текущем состоянии |
| Питание | Фото/название, порция/диапазон, допущения и источник | Сохранение без КБЖУ при unknown; не требуется вручную считать калории |
| Бюджет | Month picker, approved plan, actual, free_now, дневной ориентир, категории/обязательства/резервы, proposals | Gate unavailable без ложных цифр; incomplete FX/source помечен; нет ручной замены импорта |
| Портфель | Счета/позиции, P&L, flows, комиссии/налоги, метод/coverage calculation | Unknown quotes/cost basis не 0, удержанные налоги отдельно от предполагаемых |
| Квесты | Today, нагрузка, history, outcome/причина, recovery mode | Нет задания не провал; ошибка ИИ-назначения пересматривается без штрафа |
| Настройки | Автоподтверждение, каналы, recovery, runtime root/диск, capabilities, копии, export/delete | Опасные действия отдельным подтверждением; нет дополнительного login/Touch ID |

Обычный ввод: открыть quick assessment из menu bar/главного экрана → выбрать 1–4 поля → save. Целевой путь ≤30 секунд и ≤3 основных действий, проверяется usability/E2E; суммарные пять минут — ориентир пользовательской нагрузки, не скрытый лимит разговора.

Шрифты системные, локализация RU; цвет не единственный индикатор. VoiceOver labels, клавиатурная навигация, уменьшение движения по системной настройке. Анимации не блокируют ввод/сохранение. Prototype визуального оформления можно менять без изменения бизнес-правил.

## Telegram

Один связанный владелец, только личный чат. Pairing: локальное приложение создаёт одноразовый код 10 минут → владелец отправляет `/start <code>` → подтверждённая связь сохраняется; другие аккаунты не получают данные. Ошибка кода не сообщает существование чужого профиля.

R1 команды: `/status` персонаж/баланс с источниками, `/state` кнопки частичной оценки, `/history` последние отметки, `/help`. Уведомления по BR-07. R2: обычный текст/voice — разговор, photo — предложить записать блюдо, `/diary`, `/report`, inline confirmation extraction. R3: `/budget`, `/portfolio`, proposals approve/reject по подписанным локальным callback IDs с ожидаемой revision. R4: `/quests`, inline outcome/recovery.

В ответ на прямой запрос владельца разрешены суммы/личные выводы, но краткие proactive push без них. Голосовые и фото проходят инфраструктуру Telegram; дальнейшее ИИ-исполнение локально. Размеры: voice ≤30 минут/50 МиБ, image ≤20 МиБ/40MP, text ≤20000 символов. Бот отвечает «принято» только после durable intake на работающем Mac. Когда Mac выключен, ответов не обещаем; runtime не имитируется внешним облаком.

## Wireframe

```text
┌ Life Tracker ───────────────────────────────────────────────┐
│ Персонаж │  [2D персонаж]     Баланс: хорошо 7.5             │
│ Дневник  │  Энергия 8   Настроение 7.5   Спокойствие 8        │
│ Питание  │  Самочувствие 9   [источник + время каждого]       │
│ Финансы  │  [Отметить состояние]   [История / объяснение]    │
│ Квесты   │  Игровые атрибуты / эффекты — отдельно, с R4      │
│ Настройки│  Фон: работает · Источники: частично доступны     │
└─────────────────────────────────────────────────────────────┘
```

Числа wireframe синтетические. До R4 опыт и игровые шкалы не подставляются вместо самооценок.
